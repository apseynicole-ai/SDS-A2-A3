**C-02 · The two-tailed F critical-value rule is missing, so the decision system produces wrong critical values**

- **Location:** `#wm10` "Two variances" card (line 231). Skill `A2C10.10`. Mock A MCQ 7. Method selector "Two variances → F".
- **Evidence:** the Ch 10 deck (slides "Testing for the Ratio of Two Population Variances") says: two-tail → reject if F_stat > F_{α/2}; upper-tail → F_α. Its worked example uses F₀.₀₂₅(9,9) = 4.03 at α = 0.05. Tutorial 10 Q11 and Q12 test exactly this distinction. The supplied F tables are A (α = .05), B (α = .025) and C (α = .01). The HTML only says "larger variance in numerator; match df".
- **Why it matters:** a student following the page uses Table A (3.18) instead of Table B (4.03) for the default two-tailed test. That is a wrong critical value, and possibly a wrong decision, on a Section A question. Because the larger variance always goes on top, only upper-tail critical values exist in this convention, and the page never explains this.
- **Repair:** add to `#wm10`, `A2C10.10`, the formula map and the method selector: "Two-tail H₁: σ₁² ≠ σ₂² → compare F_stat with F_{α/2}(df₁, df₂), i.e. Table B for α = 0.05. Upper-tail H₁: σ₁² > σ₂² (group 1 = larger variance) → F_α (Table A). Only upper-tail critical values are used because F_stat ≥ 1." Add worked Tutorial 10 Q12(b) and Q14, and an MCQ that discriminates Table A from Table B.
