8.8 Bootstr apping
When one can assume that a population is normally distributed, using confidence interval  estimation 
methods 
for population parameters, such as the confidence interval estimation of the population 
mean, is a valid approach to analyzing data. However, when one cannot assume that a population is 
normally distributed, one uses other methods such as bootstrapping, which uses repeated resam-
pling with replacement from an initial sample. Because bootstrap methods are based on the original 
sample, these methods make no assumption concerning the underlying population distribution.
For example, to estimate the population mean using bootstrapping:
1. Select a random sample of size n without r
eplacement from a population of size N.
2. Resample the initial sample by selecting 
n values with replacement from the n values in 
the initial sample.
3. Compute X from this resample.
4. Repeat steps 2 and 3 m
 different times.
5. Construct the resampling distrib
ution of X.
6. Construct an ordered array of the entire set of resampled means.
7. Find the 
value that cuts off the smallest a>2 * 100% and the value that cuts off the 
largest a>2 * 100%. These values provide the lower and upper limits of the bootstrap 
confidence interval estimate of the population mean.
To use bootstrapping estimation procedures, one typically selects a very large number of resamples  
(in the thousands) and use statistical software such as JMP or Minitab. To illustrate the bootstrap 
confidence interval estimate for the population mean, return to Example 8.3 on page 254 that 
developed a confidence interval estimate of the population mean processing time of applications 
for life insurance. The confidence interval estimate assumed that the population processing time 
was normally distributed. Suppose a second insurance company did a similar study of 27 policies 
that showed that the processing time was right skewed. For this second study, the validity of the 
confidence interval developed is in doubt.

To construct a 90% bootstrap confidence interval, you need to determine the smallest 5% 
and the largest 5% of the resample means. Since 100 resamples were selected, you need to 
 id
entify the 0.05 * 100% = 5th smallest value and the 0.05 * 100% = 5th largest value. 
From Table 8.4, the fifth smallest value is 36.6296 and the fifth largest value is 51.5926. There-
fore, the 90% bootstrap confidence interval estimate of the population mean processing time is 
36.6296 to 51.5926.
